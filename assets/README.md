# assets

这里放**不随源码分发**的二进制资源。

## coc-kp.pdf

「规则书」按钮要用的 PDF：`《克苏鲁的呼唤》第七版》`（418 页）。

**这份文件不入库**（`.gitignore` 已排除）。原因有两个：

1. 它是官方出版物，有版权，不适合放在公开仓库里分发。
2. 8 MB 的二进制一旦进了 git 历史就永久存在，无法通过普通提交移除。

## 怎么让它生效

clone 之后自己放一份到本目录，文件名必须是 `coc-kp.pdf`：

```
assets/coc-kp.pdf
```

没有这个文件时：

- 主界面的「规则书」按钮仍然能点，会弹出提示说找不到文件
- 阅读器窗口里会给出「用系统阅读器打开」的退路

## 索引数据从哪来

左侧章节树的 176 条条目存在 `src/core/ruleBookIndex.js`，
是从这份 PDF 的书签提取的，**不需要 PDF 也能正常显示和搜索**——
只有右侧的页面渲染依赖 PDF 本体。

换用别的规则书时，改这个文件里的条目和页码即可。
